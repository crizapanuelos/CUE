# CUE app icon

User-supplied Green and Gold CUE Billiards Logo.png is retained as CUE-original-logo.png. The artwork itself is unchanged; surrounding blank space is trimmed and the result is centered/scaled on white for each platform icon size.

Android includes legacy density icons, round fallbacks, and Android 8+ adaptive icons. The adaptive foreground keeps the logo within the central safe region for launcher masks. Web includes favicon, standard icons and maskable icons. iOS and Windows source icon assets are also updated; those native applications have not been built in this Windows/Android task.

In-app illustrations/logos and shopping features are unchanged. Android system startup uses the launcher icon resource.
